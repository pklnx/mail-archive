# Third-party notices

The project itself is under [LICENSE](LICENSE). This file names the
third-party packages in the web UI, holds the license of the fonts that it
bundles as files of their own, and lists the non-Go code embedded in the
server binary (PDFium compiled to WebAssembly). Go modules are not listed;
they are named with exact versions in `go.mod` and `go.sum`, and each
module's license is in its folder of the Go module cache.

The web UI's JavaScript and CSS contain third-party packages, among them
React (MIT), the Carbon Design System (`@carbon/*`, Apache-2.0) and the
pklnx design system's Carbon theme (`@pklnx/design-system`,
`MIT AND Apache-2.0 AND OFL-1.1`: MIT for its own code, Apache-2.0 for the
Carbon values it builds on, OFL-1.1 for the IBM Plex fonts it ships, which
the web UI takes from the `@ibm/plex-*` packages below instead), with their
dependencies. They are listed with exact versions in
`web/package.json` and `web/pnpm-lock.yaml`; each package's license text is
in its folder under `web/node_modules` after `pnpm install`.

## PDFium, compiled to WebAssembly

The server binary embeds `internal/pdfium_wasm/pdfium.wasm` from the Go
module `github.com/klippa-app/go-pdfium` v1.21.3 (5,754,045 bytes, SHA-256
`d1dbc423597c0c65cd932cd1bb6a452fdc457a1f3b5009d3d5ec4ca768c47f53`). It
reads PDF attachments for search (`internal/attachtext`). The module is
PDFium built without V8 and XFA by jerbob92/pdfium-binaries, branch
`wasm-standalone`, patch state `e33a1ef` of 2026-08-23, as go-pdfium's
`NATIVE_VS_WEBASSEMBLY.md` states. Neither the module nor the go-pdfium
module records the PDFium revision or the Emscripten version it was built
with. The components below are those that PDFium's build files link into
such a build at `chromium/8057` (commit `a5a7089`, the revision go-pdfium's
own CI tests against); the module's strings confirm libjpeg-turbo, OpenJPEG,
FreeType, ICU, Little CMS and abseil.
